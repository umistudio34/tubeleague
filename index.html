TubeLeague

運営者個人のための YouTube チャンネル運用ツール

このアプリについて

TubeLeague は、運営者（umistudio34）が自分で所有・管理する YouTube チャンネルの運用に使う、個人用のデスクトップアプリです。一般の方に向けて提供しているサービスではなく、運営者以外のユーザーの Google アカウントにはアクセスしません。

主な機能

  • 運営者が制作した動画を、運営者自身の YouTube チャンネルへ非公開でアップロードする
  • 運営者自身のチャンネルの説明文・キーワード・バナー画像を更新する
  • 運営者自身のチャンネルの再生回数・視聴時間などの統計を取得し、次の動画づくりの参考にする

YouTube API Services の利用

TubeLeague は YouTube API Services を利用しています。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。データの扱いは プライバシーポリシー をご覧ください。

About (English)

TubeLeague is a private desktop tool used only by its operator (umistudio34) to manage the operator's own YouTube channels. It uploads videos created by the operator to the operator's own channels as private videos, updates those channels' descriptions, keywords and banner images, and reads those channels' statistics to plan future videos. It is not offered to the public and does not access any other user's Google account.

TubeLeague uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy and our Privacy Policy.
