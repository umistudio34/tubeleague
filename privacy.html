プライバシーポリシー

最終更新日: 2026年10月27日

TubeLeague（以下「本アプリ」）は、運営者 umistudio34（以下「運営者」）が、自分で所有・管理する YouTube チャンネルを運用するための個人用アプリです。本ポリシーは、本アプリが YouTube API Services を通じて取得する情報の扱いを説明します。

1. 利用する API と規約

本アプリは YouTube API Services を利用しています。本アプリの利用には YouTube 利用規約 が適用され、Google によるデータの扱いは Google プライバシーポリシー に従います。

2. 取得する情報

本アプリは、運営者が OAuth で許可した運営者自身の YouTube チャンネルについてのみ、次の情報にアクセスします。

  • チャンネル情報（チャンネルID、チャンネル名、説明文、キーワード、バナー画像）
  • 運営者がアップロードした動画の情報（タイトル、説明文、公開状態）
  • 統計情報（再生回数、高評価数、コメント数、視聴時間、平均視聴率、登録者の増減、推定収益）
  • OAuth のアクセストークンと更新トークン

運営者以外のユーザーの個人情報、コメントの内容、視聴者を個人として特定できる情報は取得しません。

3. 利用目的

  • 運営者が制作した動画を、運営者のチャンネルへアップロードするため
  • 運営者のチャンネルの説明文・キーワード・バナーを更新するため
  • 動画の成績を集計し、今後の動画の企画を改善するため

4. 保存と管理

取得した情報と認証トークンは、運営者の PC 内にのみ保存し、外部のサーバーには保存しません。統計情報は、成績の比較に必要な期間だけ保持します。

5. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。広告目的にも利用しません。

6. Cookie など

本アプリはデスクトップアプリであり、Cookie などで利用者の端末に情報を保存・取得することはありません。このウェブサイトも Cookie を使用していません。

7. アクセスの取り消しとデータの削除

本アプリへのアクセス許可は、Google アカウントのセキュリティ設定（サードパーティ アクセス） からいつでも取り消せます。取り消すと本アプリは情報を取得できなくなり、運営者の PC に保存された認証トークンと統計情報は削除します。データの削除に関するお問い合わせは、下記までご連絡ください。

8. 変更

本ポリシーを変更する場合は、このページで最終更新日とともにお知らせします。

Privacy Policy (English)

Last updated: October 27, 2026

TubeLeague ("the App") is a private application used only by its operator, umistudio34, to manage YouTube channels the operator owns.

YouTube API Services. The App uses YouTube API Services. By using the App you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information accessed. Only for the operator's own channels that the operator authorizes via OAuth: channel information (ID, title, description, keywords, banner), information about videos the operator uploaded (title, description, privacy status), statistics (views, likes, comment counts, watch time, average view percentage, subscriber changes, estimated revenue), and OAuth tokens. The App does not access other users' personal data or comment contents.

Use. To upload the operator's videos to the operator's channels, to update those channels' description, keywords and banner, and to analyze performance to plan future videos.

Storage. All data and tokens are stored only on the operator's own computer and are not stored on any external server.

Sharing. The App does not sell, share or disclose any data to third parties and does not use it for advertising.

Cookies. The App does not store or read cookies or similar information on any device. This website does not use cookies.

Revoking access and deletion. Access can be revoked at any time via the Google security settings page. Upon revocation, the operator deletes the stored tokens and statistics. For deletion requests, contact us below.
